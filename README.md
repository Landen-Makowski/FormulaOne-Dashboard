# OpenF1 Dashboard

This project is a single-page web application that uses the OpenF1 API to display Formula 1 race and session data.

The project will also use a weather API to provide weather information for race locations.

Technologies

HTML

CSS

JavaScript

OpenF1 API

Fetch API

# Purpose

The goal of this project is to practice retrieving public API data with JavaScript, working with JSON, and dynamically displaying information on a web page.
